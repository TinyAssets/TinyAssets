# Parent request economy

Ordinary accepted HTTP chat uses a text-only invocation with no connected tools
or automatic learning. An agent turn shares one allocation across rounds,
retries, accepted-source fallback, helpers and review. Local metered-free policy
allows three text attempts, six agent attempts across sources, and at most two
consecutive failures on a source. These limits do not assert a provider balance.
Paid, native, local and explicitly unmetered contracts keep their own policy.
The installed source data identifies any legacy free-model suffix; the request
budget contains no vendor-specific host rule.

A durable owner/command-center/parent allocation reserves before dispatch.
Single-use broker references bind the accepted source, current grant, model,
request and operation. Every actual send, including an OAuth resend, has its
own reservation and failed/internal usage evidence. A timeout after dispatch
stays counted. Missing authority, cancellation and expiry cannot create a send.
Exhaustion records bounded continuation, never approval or automatic resume.

An admitted asynchronous child retains participation in its existing run-owned
allocation before launch. Parent completion releases the parent's participation;
the final participant closes the allocation. Each child still admits against
its own run and receipt. A released run cannot admit another child, and explicit
allocation closure fences every participant. Borrowed chat allocations retain
the chat owner's close policy. Family membership never nests budget locks;
forked copies cannot release or extend the originating process's allocation.

The CI repair preserves mixed HTTP-to-native tool history by exercising an
explicit tool request. Diagnostics, shared-self, provider-switch and receipt
fixtures retain their original behavioral assertions and now provide the added
accounting collaborators or assert the added usage projection. A pool-atomicity
fixture isolates the pool limit; a separate two-401 test proves the default
consecutive-failure stop before any extra effect. Definition reads use the
bounded no-symlink universe reader before issuing authority references.

Synthetic proof covers delayed unpublished public/private children, shared
allocation exhaustion, cancellation, admission/close races, GC lock ordering,
actual fork copies, symlink refusal, retries, source fallback, learning and
zero-extra-effects stops. No provider request, account access or incident replay
is part of this proof. Hosted run/job URLs and exact-head results are recorded
on PR #4409; a skipped workflow or failure before jail execution is not proof.
