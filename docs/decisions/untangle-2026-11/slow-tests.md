# slow-tests as built (2026-11-16)

`slow-tests` (`tests.yml`) ran `pytest -m slow` on the merge-group commit. The shape prune removed every `slow`-marked test, so it collected nothing and passed on pytest's exit 5, while every merge group installed Python, the browser extras and Chromium for it. The founder removed it from the "main merge queue" ruleset (24065294) and the classic branch protection on `main` on 2026-11-16; both now require `Diff scope declared`, `required-tests` and `invariants` (read back from the API before this change).

The last one also claimed the inventory test runs off the required lane, false since #4238.
2. **Reused from `land/3`:** the job's deletion, the ruleset mirror, `enqueue_merge.py`, the three test cuts, and the two comments. **Not reused:** the cap and facet probes' deletion, which `land/3` carried too (they went on `main` since); and its `test_the_slow_marker_stays_until_the_cutover`, a test that pins a line in `pyproject.toml` and checks no behaviour.
3. **Left, with the old stack:** the `slow` marker in `pyproject.toml` and `ci_required_tests.py`'s `not slow` filter. No test carries the marker, so the filter selects everything, but `pyproject.toml` is in `build-image.yml`'s push paths, so editing it redeploys the old daemon; both go at the cutover's deletion (`tasks.md`, the cutover).
