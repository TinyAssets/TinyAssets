# O1d as built (2026-11-15)

B3's fourth and last PR, as `o2.md`'s "B3's shape" and `o1c.md`'s owed list: runs, launch, signins and restore on their needs, `OwnerState` deleted, the object's parts one plain record, the layer row, and S9's run ids through `stop`. B3 is done.

1. **Three modules on `DoorNeeds`:** `RunsDoorNeeds`, `SigninsDoorNeeds` and `RestoreDoorNeeds`, by `o1.md` item 3's rule. `runs.ts`'s `initiated` loses its unused state parameter.
2. **The launcher's constructor takes `LauncherNeeds`** (d2's constructor style, which the launcher keeps since the object alone builds it): the 93 `this.#o.` reaches keep their spelling, held to an interface in `launch.ts`, and `LaunchState` goes. The object hands it a literal of what it reaches. The relay is built before it: its `live` is a function of the object's, so the one cycle (launcher and relay) needs no getter. `RunHost` was already exactly what `Runs` calls, so it is not cut further.
3. **`OwnerState` is deleted.** The runner hands every handler the object's parts (`#parts`): one frozen record made at the end of the constructor, of the stores, the modules the object builds (`Built`), the units and the reads, with no getters. Its type (`Parts`) is private to `owner-do.ts`, and `HANDLERS` holds it to every module's needs (`DoorsOf<M, Parts>`). Each member of `Built` was removed in turn, and `tsc` refused every removal at `HANDLERS`. `OwnerState.admitted` and `#admitted`, which nothing read, go.
4. **The layer row:** no `owner/src` module imports `owner-do.ts` but the owner Worker's entry (`index.ts`, its own layer). A test, a memory leg and a guard may, through their workspace's layers. With `o1b`'s `eager`, no owner module loads it at run time either.
5. **S9's run ids through `stop`** (`s9.md` item 7): `RunHost.stop` and `Launcher.stop` take run ids, and `Runs.cancel`, `endClient`, `endAll` and `lost` answer them. `liveRuns` keeps its leases, which the launcher's lease check reads; the erasure's `ended` maps it to ids.
6. **`runs.test.ts`'s stand-ins go:** `hostOf`, its 18 throwing members (the `tiers` one too) and the two hand-built `Runs`. Their tests reach the object instead.
   - "The lane's race": a waiting run's agent file, past an inline file, is read through the files plane between the lane's pick and the run's admission. The owner is suspended while the read is held at the gate, and the admission refuses it, never started.
   - "A waiting run's turn": the tier numbers a door last handed (1, none, 2) decide whether the line's ring starts the run waiting in its own conversation, and never the one behind a live run.
7. **`write-gate`** reads the units in the parts record, not `#stateOf`. `memory/probe.ts` and the other `ownerStores` builders need no change: `ownerStores` is as it was.
