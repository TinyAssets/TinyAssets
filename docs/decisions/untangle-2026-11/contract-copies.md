5. **The guard:** a third kernel in `ci/kit/kernels.ts`, the object test, home `checks.ts`, in every layer that may import the contract. A `whole` or a sorted-key string has no such cheap mark, so the guard holds only the object test, the kind that was copied a fifth and a sixth time.
