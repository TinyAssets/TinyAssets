# D3 as built (2026-11-14)

1. **Each binding is built through its kind's parser.** The binder's `bound(env, kind, binding)` runs `BINDING_PARSERS[kind]` on a literal typed as that kind, so a field the kind lacks is a type error and a value out of its grammar is the parser's `invalid` refusal. The binder's own copies of the grammars go (`KEY_ID`, the hex and run checks, `seconds`, the vendor shape); its cross-checks stay (a grant's props against its token, a key registration's entry against the owner). A malformed field reaches the binder only from the doors' own data (a grant's props, a directory entry), never from a request, whose key and run ids are parsed first, so the answer changes from a fault to the contract's `invalid` only for a bug.
2. **`withTiers` is `withAccount`** (`d2:N80`), typed over the two kinds that carry the control record's gates, account and inbound. It doesn't parse again: both parsers take `tiers` and `signins` as read, so the binding keeps its kind.
3. **`ownerOf` refuses every reserved name** (`reservedOwner`). A subject that starts `rehearsal-` but isn't a rehearsal's name is refused too, and the case stays after the cutover, so the manifest no longer lists it or the binder's `rehearsalRun` import.
4. **The doors' queue entry dispatches by name with no fall-through.** A batch of any other queue throws. The ring and the erasure are named by `QUEUES`. The import's case keeps the window's own `IMPORT_QUEUE`, because the binder guard keeps the window's binding names (`IMPORTS`) inside `import.ts`. The doors' config guard holds the consumers to `QUEUES`, which makes the two names equal, and the case and the constant go together at the cutover. `ERASURE_QUEUE` and its guard go.
5. **The two loopback rules are named.** `localOrigin(url)` is the binder's rule: a local client's redirect, whose port names no installation, by the provider's count. `loopbackRedirect(url)` is the apps' RFC 8252 §7.3 match. Each takes the URL, so neither file repeats its own protocol-and-host test. Behaviour is unchanged.
6. **Owed, lane O:** `owner/src/sessions.ts` `ttlS: 28_800` still copies `SESSION_TTL_S` (O4). The doors had no copy left in source; their session test now reads the constant.
