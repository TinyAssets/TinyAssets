# O1b as built (2026-11-15)

B3's second PR, as `o2.md`'s "B3's shape" and `o1.md`'s owed list: the four widening proofs, the policy stores on `DoorNeeds`, the tier folded into the admission, and the policy-boundary guard cut to a cast rule. Owed: `untangle/o1c` (files, collections, ledger, import) and `untangle/o1d` (runs, launch, signins, restore, `OwnerState` deleted).

1. **The proofs are declared in `door.ts`:** `LiveSession` (`{ hash }`), `OwnerSelf`, `PlatformLine` and `ImportLine`. Each is a kind (`proved`, read at run time) and a brand no value holds (`minted`, typed by a declared `unique symbol`, so only a cast makes one). The brand is a named property, not a computed key: the alarm guard refuses a member by a computed name.
2. **A call carries its caller's proof alone.** `Call<R, K>` is `Checked<R>` and, by `K` (the row's `caller`, `CallerOf<D>` in `HandlerOf`), `call.session`, `call.self`, `call.platform` or `call.importing`; a call of no one caller carries none. `Door<R, K>` checks to that call. The string `Call.session`, `""` on every other row, goes.
3. **The maker.** The runner mints every proof, per call (`mintProof`, `proof-mint.ts`): `#within` adds a row's own once `#bound` held for its caller (`#ownerOf` for the owner rows, the reserved bind, the import bind), and a session row's `LiveSession` of the hash `Sessions.live` (a check) returns. `proven` refuses any proof it did not mint: its run-time brand is a private field (`Minted`), which no copy, spread, proxy or prototype of a minted proof holds; and a minted proof has no prototype, so its holder reaches no `constructor` to mint another kind with (review 3: a session row's `call.session.constructor` had made a `PlatformLine`). `door.ts` may name the kind, never the mint (`forged`). A proof is live only while the door's call that minted it runs: `#leased` hands its steps a `Lease` and ends it once the call settles, so a proof a store kept past its call is none at a later call (review 3).
   - **The mint is a module only the runner and the check import** (`owner/src/proof-mint.ts`; the layer table's `SOLE_IMPORTERS`, `ci/kit/layers.ts`): `owner-do.ts` mints with it, and `door.ts`'s `proven` reads its brand (`isMinted`), which only the mint's class body can read, so the check and the mint share the module and `door.ts` is its second importer. Any other module importing it, by any way an import is made (a type one, a re-export, an `import()`), fails the `ci` isolation guard: an owner source, a test, a memory leg and a guard alike. So no test mints a proof: the tests that widened on a store with a real session (`inSession`, gone) make the same changes through the doors.
   - **A Worker's source loads no module at run time** (the layer's `eager`): an `import()` or `require()` there, a literal one included, fails the isolation guard, so no handler reaches the runner (`import("./owner-do")`, its `ownerStores`) or the mint by a load its imports do not show. A computed one was refused already ("imports a computed module"); a literal `import()` was not: the layers allow `owner/src` to import `owner/src`, and `owner-do.ts` stays importable as a type until `untangle/o1d`'s layer row. No Worker's source loads one today.
   - **Review: only the runner mints.** Before, an account row's handler could widen with `o.policy.changed(o.sessions.live(binding.session, now), …)`, and narrowing `live`'s type alone still let `… as never` or `import("./owner-do")`'s `ownerStores` through, and a proof's kind built at run time (`JSON.parse` of a split template) passed `proven`. Now `Sessions.live` returns the row's hash, no proof, and `proofs.test.ts` holds an unminted proof of the right kind refused. `o1c`'s `FilesDoorNeeds` takes `live` as a check (its result unused).
4. **Each widening takes its proof first and checks it (`proven`), a loud `Error` without it.** `grants.set`, `grants.forgetRevoked`, `keys.add`, `policy.write`, `policy.changed`, `policy.applyKeyRequest`, `registrations.take` (`LiveSession`); `sessions.open`, `sessions.extend` (`OwnerSelf`); `admission.set`, `admission.setTier` (`PlatformLine`); `policy.imported` (`ImportLine`). `grants.forgetRevoked` is one more than the guard's `WIDENS` held: its own doc calls it a widening, and it receipted the session id the proof now carries. `Policy.imported`'s write is the private `#write` under `import`, so the public `write` takes only a live session. The connections' flows take `session.hash`.
5. **`ownerStores` builds `Sessions`, `Keys`, `Registrations` and the admission (`OwnerAdmission`)**, so a test reaches each with no stand-in. The tests that called a widening straight on a store (`grants.test.ts`'s four, `policy.test.ts`'s, `registrations.test.ts`'s and `admit.test.ts`'s, a cast stand-in for the storage) make the same changes through the doors, with a real session (review: no test may mint a proof); the narrowings and reads they check after go on the stores.
6. **`tier.ts` is folded into `admission.ts`.** `OwnerAdmission` holds the admission row (`row`, `unadmitted`, `admitted`), the tier (`tier`, `setTier`) and the kept numbers (`tiers`, `numbers`, `keep`), and `set` (today's `setAdmission`). `tierSet` and `tierRead` are the `admission` module's rows (`contract/doors.json`, `door-map.ts` regenerated). `OwnerState`'s `admission()`, `tier()`, `unadmitted()` and `setTier()` go for one `admission` member; the launcher and `Runs` read it (`RunHost.tiers`). `workRefusal` is the module's own.
   - **The refusals' homes:** `files.ts`, `launch.ts` and `runs.ts` imported `tier.ts`, and only the object may import `admission.ts` (policy-boundary's `MODULES`, a list that only shrinks). So `TIER_RUNS` is `runs.ts`'s, its one thrower, and `TIER_UNREAD`, thrown by the files' byte bound and the admission's `numbers`, is `files.ts`'s, which the admission imports (review: no worker but the owner reads it, so it is no contract value).
   - **`runs.ts`'s keeps go:** `agentSubmit`'s and `agentRun`'s `tierNumbers(storage, binding.tiers)`, and `agentRun`'s second keep, read `o.admission.numbers()`. `#bind` kept the binding's numbers in the same unit (`o1.md` item 8), so each read is what the keep returned.
7. **`Launcher.endClient(client, now)` and `endAll(now)`** stop what `Runs.endClient` and `Runs.endAll` end: `grants.ts`'s `endClient`, `#runAccount`'s stale stamp, `admissionSet`'s suspension and the restore's pin. The erasure's `ended` keeps `stop(runs.liveRuns())`: it stops the runs the wipe then deletes, and `endAll` would cancel each first, a write the erasure never made.
8. **`GrantRequest` and `RegisterRequest` are deleted, not moved.** Each was a typed copy of a module's own shape that its readers cast to: `grants.ts`'s `GrantChange` (now exported, `grantSet`'s request) and `ledger.ts`'s `Registration` (`registerAgent`'s). `keyMint` hands `grants.set` its change uncast, and `registerPropose`'s request is its card's `Fields`.
9. **The policy modules declare their `DoorNeeds`:** sessions, keys, grants, policy, admission and registrations, by `o1.md` item 3's rule (a guarded module's reach as method signatures, the rest as `Pick`).
10. **Guards:**
    - `policy-boundary`: the widening half goes (`STORES`, `ROOTS`, `STATE_TYPES`, `WIDENS`, `OTHERS`, the `o` naming rules and their cases). `forged` takes its place: a type assertion naming a proof's type, or the kind's name (`proved`) in any spelling (a key, a shorthand, a computed key, a string or JSON text; review: a shorthand, a computed key and a `JSON.parse` had passed it), or the name of the mint (`mintProof`), outside the runner (`owner-do.ts`) and `door.ts`. `platform_tiers` is `admission.ts`'s.
    - `ledger-boundary`: `REACHERS`, `REACH` and their case go; the `DoorNeeds` declare the reach.
    - `write-gate`: `launcher.launch`'s ask is a unit argument (the launch's admission unit calls it). The tier read in it was a free function the guard did not see; it is a store's now.
    - `admission-caller`: unchanged. Nothing it names moved.
    - The cutover manifest: `door.ts`'s `ImportLine` and `owner-do.ts`'s are edits of the cutover; the policy-boundary edit (`policy.imported`) goes with the list that named it.
11. **`call.self` is read by member** (`call.self`, never destructured to `self`): the module-state guard reads an identifier `self` as the global.
