# F2 developer tool profiles as built (2026-11-18)

The public developer reference described seven Python handles. The platform serves a
tool profile for each authenticated MCP caller. A static site can show the contract's
inventories. Only the caller can ask for its effective list. The owner may narrow a
custom profile or disable code mode, and operations still require authority.

The developer page now builds its disclosures from the entries of
`platform/contract/profiles.json`. The Pages publisher watches that input. Full tool
descriptions and arguments link to the door contract. Local contributor instructions
use the platform workspace and its declared Node version. The website opens no MCP
connection to build this reference.

The real export produced 28 pages. The site's 41 tests passed. Chromium opened each
profile and compared every displayed tool at 390 and 1280 pixels. An independent
alternate build reordered the catalog, emptied one list, changed membership and added
a fourth profile. The exported disclosures matched that catalog in order at both
widths, including with an unrelated disclosure on the page. The public page contains
only the profile names and tool inventories from this input.

This joins the public connection guide in the single site release after routes. The
founder supplies the privacy and account-deletion copy. The listing submissions and
signed-in client checks remain separate steps.
