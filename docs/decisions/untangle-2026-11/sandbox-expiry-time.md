# Sandbox expiry time as built (2026-11-26)

The provider's sandbox detail defines expiry as a date-time. Its Go implementation returns the expiry for a running sandbox and a historical time for a paused one. Both are valid. [Provider schema](https://github.com/e2b-dev/E2B/blob/main/spec/openapi.yml) and [detail handler](https://github.com/e2b-dev/infra/blob/86cb50338fe3bd73c10b13270aaa576b48f5d582/packages/api/internal/handlers/sandbox_get.go#L270-L280).

On main `d662e63e` the adapter accepted any string. Eight lifecycle callers separately parsed it. A synthetic invalid response caused the ordinary Worker alarm to terminate a running job on an older runner during its valid window. On the corrected branch the original sandbox, saved deadline and job survive, the normal failure counter increments, and the next valid observation clears the failure. No live provider was contacted.
