---
name: starter-images
description: Generate or edit images with an owner-connected image-capable model through ta.
---

Discover `ta search image`, then `ta search connection` if needed. Describe the
actual image-capable connection/tool returned by discovery. Check its schema
for generation vs editing, accepted formats, prompt, sizes and reference inputs.
Never assume a text model can create images or invent a provider tool name.

If none is connected, say: "Connect an image-capable model or image-generation
service so I can create this." Use starter-access and the connect skill for the
owner-approved connection flow; no platform or maintainer credentials. Do not
send private reference images to another service without the owner's authority.

Invoke the discovered capability through `ta <name> --json '<arguments>'`, with
JSON built safely from the user's prompt and the real schema. Inspect the actual
result and errors. Save generated bytes in an owner-chosen file, verify type and
nonempty content, and deliver using starter-workspace file guidance. If a tool
returns a job ID, poll its documented status operation; a job ID is not an image.
Report missing compute, rejected requests and failed downloads plainly. Never
present a mock image or unverified URL as a generated result.
