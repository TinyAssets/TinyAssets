# Design

A single writer prompt node declares tools_allowed: [universe_self]. This is an explicit capability in the admitted immutable Branch, not a flag accepted from run inputs. Other branches retain existing behavior. After provider admission, the session rechecks the current named owner's home and admin ACL, then reuses universe_intelligence's persona builder, conversation formatter and sandboxed engine MCP ModelConfig. The existing provider session still owns assignment, credential snapshot, invocation budget, branch identity and cancellation. Multiple prompt nodes or non-writer marked nodes refuse. Missing engine tools refuse rather than executing with partial access.

The wake reads the same principal:<verified owner> session as converse. Recent history is the normal working set; read_graph target=conversation can retrieve all retained older messages. Its caller pins owner and universe, rechecks current ownership, returns an untrusted envelope and exposes no session/path selector. Metadata paging uses a stable before-message-id cursor; content paging is lossless Unicode chunks. Reads use SQLite mode=ro without schema changes and reject a symlinked store. Already deleted history cannot be recovered and must never be claimed available.

No converse call, learning extractor, or synthetic founder exchange is invoked by a wake. Shared brain mutations still use the same governed tool as chat. Current goals, runs, branches, requests and connections are read using the same live tools. The task prompt remains the founder's one-line cofounder direction, with a single string output so the compiler adds no JSON contract.

Acceptance: focused tests plus independent shape/basic-safety review; exact-head CI before landing. Live proof must inspect actual tool use from an opt-in wake, including an older conversation message outside its initial window and a current brain read. Repeat after a new founder message to establish freshness. No live parity claim before deployment and those checks.
