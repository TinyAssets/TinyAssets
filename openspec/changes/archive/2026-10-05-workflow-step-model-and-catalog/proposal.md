## Why

Workflow policies can fall through to an unrelated provider. Model metadata is
process-local although engine tools run in replaceable subprocesses, and a
confirmed additional model connection is registered without accepted membership.

## What Changes

Honour workflow model pins without implicit substitution, retain owned advisory
catalogue refresh results across processes, and accept an owner-confirmed model
connection while preserving the current serving source and existing limits.

## Impact

Graph compilation, workflow candidate ordering, native shortlist caching and the
confirmed connection completion path. No app.html edits or new public tool.
