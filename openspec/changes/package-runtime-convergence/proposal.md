## Why
C10 removes executable extension discovery outside revision-bound activation and retires platform workflow/package and paid-market duplicate paths (shape-convergence S6/S7/B1).

## What Changes
- Discover extensions only through the activated v2 package catalog.
- Admit durable activities as agent sessions instead of seeding an Activities branch.
- Convert legacy invoke/await workflow nodes once before retiring their runtime.
- Register public and pinned engine profiles at one boundary; preserve scoped handlers.
- Remove executable bid/treasury/paid escrow routes without deleting stored history.

## Impact
Owner authority, invocation budgets, cancellation and immutable migration receipts are floor boundaries. Requires cross-family review and migration/restore evidence before protected deployment. C6 owns runtime boxes, C12 owns shared export/package integration, C11 owns UI.
