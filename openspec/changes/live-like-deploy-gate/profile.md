The live-like fixture is driven by `deploy/live_like/shape-profile.json`, a redacted structural profile seeded from the code census. On the lead's machine, run `scripts/live_like/refresh_profile.sh <backup.tar.gz>` against a local backup; the command extracts into a temporary directory, generates a read-only profile, checks every emitted string against source vocabulary, prints missing shapes against the committed profile, and removes the extracted data on exit. A refresh is reviewed as a JSON diff before committing; production data stays on the lead's machine. CI runs `python scripts/live_like/shape_profile.py diff` to reject code stores and CREATE TABLE additions that lack profile and fixture coverage.
