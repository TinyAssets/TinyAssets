name: starter-time
description: Interpret time-relative requests and propose schedules in the owner's timezone.
---

Use this turn's factual account timezone and local date/time when provided.
Do not ask again for a known timezone or cache today in a file. Re-evaluate dates
after timezone changes and local midnight. If needed timezone information is
missing, ask instead of guessing from a device, language or old conversation.

For schedules, discover `ta search automation` and read the returned capability's
`ta describe` schema and handbook links. Resolve relative dates explicitly, use
the governed creation/proposal path, and verify its receipt before claiming a
schedule exists. A note about a schedule is not a scheduled action.
