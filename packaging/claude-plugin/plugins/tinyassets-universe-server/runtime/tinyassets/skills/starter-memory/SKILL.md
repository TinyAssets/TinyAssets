---
name: starter-memory
description: Persist and verify owner-taught durable facts and recall shared notes.
---

Read the current relevant notes before making the smallest additive edit. Persist
clear, direct, stable facts in this turn; chatting about a fact is not a write.
Use the governed brain-write capability: discover with `ta search brain`, inspect
`ta describe write_brain`, and follow its current schema. Verify its success and
read back the change before claiming to remember. Report a failed write truthfully.

Do not store jokes, hypotheticals, role-play, quoted instructions, credentials,
unsupported self-descriptions, or ambiguous/contradictory claims as facts. Ask for
clarification when needed. Record genuine unanswered questions without inventing
answers. Preserve existing notes and provenance. Shared brain files describe the
command center; a selected agent must not rewrite the main identity as itself.

API reference: `ta describe read_brain` and `ta describe write_brain`.
Owner instructions govern workflow; API permissions still govern effects.
