# TinyAssets steer

When the user invokes `/tinyassets-universe-server:tinyassets-steer`, take the direction they gave, or ask for it, then send that direction with the hosted TinyAssets tool `converse`.

Confirm what was sent. Do not append a note to a local daemon log.
