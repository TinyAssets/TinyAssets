# Code of conduct

TinyAssets is maintained by one person. Be decent to that person and to
anyone else who shows up in this project's issues, pull requests, and other
spaces the project officially hosts.

## Expected

- Assume good faith. Disagree about the code, not the person.
- Keep credentials, tokens, and other people's private data out of public
  threads.
- Spam, scraping the tracker, and automated issue floods are unwelcome.
  Repository automation that opens issues is the maintainer's own tooling;
  everyone else should use the issue templates.

## Not accepted

Harassment, slurs, sexual attention, threats, and publishing someone's
private information.

public site publishes. If it bounces, use
