Make the TinyAssets Review App

One click makes a private GitHub App owned by the TinyAssets organization. It has no webhook and three repository permissions: checks (write), commit statuses (write) and metadata (read).

  1. On GitHub, click Create GitHub App (you must be an owner of the organization).
  2. GitHub opens the Platform setup workflow with ?code=… in the address bar. Copy that code. It works once, for one hour.
  3. Click Run workflow on main and paste the code into review_app_code. The workflow stores the App's key in the main-only review environment and its id as REVIEW_APP_ID.
  4. Install the App on the TinyAssets repository: the run's summary gives the link.

The code is the only secret on this path, and the workflow spends it in its first step. If the run fails before then, make the App again: delete the first one in the organization's settings (Developer settings, GitHub Apps).
