Make the TinyAssets Review App

One click makes a private GitHub App owned by the TinyAssets organization. It has no webhook and three repository permissions: checks (write), commit statuses (write) and metadata (read).

  1. On GitHub, click Create GitHub App (you must be an owner of the organization).
  2. GitHub opens the TinyAssets repository with ?code=… in the address bar. Copy the whole address. The code works once, for one hour.
  3. Give it to Claude on your own computer, and nowhere else: not a workflow, an issue or a chat others read. It runs python scripts/platform_setup.py review-app with your own gh, which stores the App's key in the main-only review environment and its id as REVIEW_APP_ID.
  4. Install the App on the TinyAssets repository alone, from the link it prints.

Whoever turns the code in first gets the App's private key, so keep it off anything shared. If it went anywhere else, or the hour passed, delete the App in the organization's settings (Developer settings, GitHub Apps) and make it again.
